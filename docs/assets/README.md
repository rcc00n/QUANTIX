# Presentation assets

The QUANTIX lockup, symbol and wordmark are unchanged copies of the supplied PNG
brand assets used by the application. Their transparent backgrounds are preserved.
The README uses GitHub's `#gh-dark-mode-only` and `#gh-light-mode-only` image
fragments: the full light wordmark appears on dark surfaces; the colored symbol and
text heading remain readable on light surfaces. The name is QUANTIX only.

Application colors: background `#0a0e13`, foreground `#edf2f7`, cyan `#69ddeb` and
secondary violet `#9b96f3`. The local SVG badge states the implemented paper-only
constraint; it is not a CI, coverage or performance badge.

## Actual screenshots

`workspace-desktop.png` (1440 × 1000) and `workspace-mobile.png` (390 × 844)
were captured on 2026-11-24 (UTC−06:00) from a separate local copy of the current

They show the unauthenticated `/login` route with empty inputs. No dashboard data,
market data, private financial information or credentials were supplied. No API
responses were fabricated. The backend was deliberately unavailable to this copy;
the sign-in form was not submitted. These are UI captures, not proof of successful
authentication, live collection or financial execution.

The original working application, deployment, databases and Telegram consumer were
