# QUANTIX 0.7.1 — public source release candidate

**PAPER ONLY. No real exchange orders.**

This is a release-note candidate for the first public source package of the existing
`0.7.1` project. It is not a new historical release and does not change the original
source chronology. The release tag/date must identify the actual published commit;
see [HISTORY_IMPORT.md](../HISTORY_IMPORT.md).

## Included source capabilities

- Public REST/native WebSocket collection, canonical identities, timestamp confidence
  and bounded recovery/storage.
- Exact depth, fee, market-rule and executable CAD FX research.
- Delayed independent paper legs, owned reservations and immutable accounting.
- Funding policies, independent Strategy Lab profiles, common opening evidence and
  shared-frame valuations with explicit missing data.
- Authenticated terminal, analytics, evidence inspection and bounded exports.
- Separate Telegram infrastructure and optional disabled explanatory AI.

## Public packaging follow-ups

The reconstructed import preserves 1,440 module/history commits. Four ordinary
later commits repaired the test container's file layout, made existing synthetic
fixtures independent of runner uptime and unrelated fixture owners, configured a
credential-free CI environment and documented local startup without a Telegram
consumer. Existing test assertions and production financial logic were preserved.

The showcase/case-study additions document actual source and clearly labeled
synthetic UI fixtures. They are not newly executed trades or profitability results.

## Verification and limits

For snapshot `157fb407`, [CI run 45523746677](https://github.com/rcc00n/QUANTIX/actions/runs/45523746677)
passed 883 backend tests, TypeScript/production build, core startup and 25 browser
cases; five opt-in live checks were skipped. A release assembled after documentation
changes should link its own final green run before publication.

No production deployment, live exchange acceptance, live Telegram receipt,
real-money readiness or recurring offsite recovery certification is implied.
The optional notification consumer stays disabled in CI without a provisioned token.
